# Sales Analytics Dashboard

An end-to-end data analytics portfolio project using Python, Pandas, SQL, and Streamlit. Includes an ETL pipeline, SQL analytics, interactive dashboard pages, charts, and AI-generated insights.

## Setup

1. Create and activate a Python virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Copy `.env.example` to `.env` and configure your database/API credentials.
4. Run `streamlit run streamlit_app/app.py`.

## Pipeline

Raw sales data → cleaning and transformation → feature engineering → database loading and SQL analysis → Streamlit dashboard and AI insights.

## Modules

- Data generation, cleaning, and feature engineering
- SQL schema and business analysis queries
- Multi-page Streamlit dashboard
- Charts and AI insights
- Power BI implementation specification

Do not commit real secrets or credentials.
